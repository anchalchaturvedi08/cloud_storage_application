## 📘 Introduction

**Cloudify** is a personal storage and file sharing web app.  
Users can upload, manage, and share files with ease through a clean and responsive interface.  
It’s built for learning and real-world use, with focus on authentication, storage handling, and modern UI design.

---

## ⚙️ Tech Stack

- **Next.js 15**
- **React 19**
- **TypeScript**
- **TailwindCSS**
- **ShadCN UI**
- **Appwrite**

---

## 🔋 Features

- 🔐 User Authentication with Appwrite  
- 📂 File Upload, Rename, Delete  
- 📤 File Sharing between users  
- 📊 Dashboard showing storage stats  
- 🔎 Global File Search  
- ⚙️ Sorting by date, name, or size  
- 📱 Fully responsive modern UI

## ⚡ Setup and Installation

**1️⃣ Clone the repository**
```bash
git clone <your-repo-url>
cd <your-repo-folder>
````

**2️⃣ Install dependencies**

```bash
npm install
# or
yarn install
```

**3️⃣ Run the development server**

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

---

## 🌐 Environment Variables

Create a `.env.local` file in your project root:

```env
NEXT_PUBLIC_APPWRITE_ENDPOINT="https://cloud.appwrite.io/v1"
NEXT_PUBLIC_APPWRITE_PROJECT="<YOUR_PROJECT_ID>"
NEXT_PUBLIC_APPWRITE_DATABASE="<YOUR_DATABASE_ID>"
NEXT_PUBLIC_APPWRITE_USERS_COLLECTION="<YOUR_USERS_COLLECTION_ID>"
NEXT_PUBLIC_APPWRITE_FILES_COLLECTION="<YOUR_FILES_COLLECTION_ID>"
NEXT_PUBLIC_APPWRITE_BUCKET="<YOUR_BUCKET_ID>"
NEXT_APPWRITE_KEY="<YOUR_APPWRITE_KEY>"
```

Replace the placeholders with your Appwrite credentials.

## 💻 Usage

1. Sign up or log in.
2. Upload files to your Cloudify storage.
3. View, rename, delete, or share your files.
